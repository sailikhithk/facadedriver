FacadeDriver Architecture

Model-agnostic orchestration layer for multi-LLM production systems

Request flow

  • 1. App calls generate(route, messages)
  • 2. Router resolves route to model chain
  • 3. CircuitBreaker checks per-model health
  • 4. Backend.generate calls provider SDK
  • 5. On failure: retry, then next in chain
  • 6. TelemetrySink emits structured event
  • 7. Response returned with full metadata

Resilience guarantees

  • Per-model circuit breaker (global health)
  • Configurable retry count + backoff
  • Automatic fallback chain traversal
  • Telemetry never breaks the request
  • AllProvidersFailedError with chain + errors
  • Circuit-open models skipped, circuit_trip set

Pluggability

  • Backend is a runtime_checkable Protocol
  • RawSDK, LiteLLM, Mock backends built in
  • Plugin discovery via entry_points
  • Custom routers and telemetry sinks
  • Lazy SDK imports (install only what you use)
  • Sync and async share the same API

Operational surfaces

  • CLI: swap, routes, replay
  • FastAPI server: /generate, /routes, /health
  • Prometheus exporter + metrics server
  • YAML / dict config with env var expansion
  • Per-request cost, latency, token telemetry
  • Structured logs via structlog / file sinks
